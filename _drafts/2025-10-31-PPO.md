PPO algorithm has reached billboard now.

In multi agent reinforcement learning systems, PPO has been used for OpenAI five to train Dota II.

How to practice PPO?
For multi-agent training, games are best way. 
PettingZoo has good collection of RL environments with support for multi-agent training.
You can also setup custom environment and train multi-agent models.


## Qwen's PPO
In Qwen LLM technical report, they mention use of PPO. 
> PPO process involves four models: the policy model, value model, reference model, and reward model.
Policy model is the pertained language model. The model is frozen during PPO training to solely focus on learning value model. This way the value model learns to adapt to various reward models.
